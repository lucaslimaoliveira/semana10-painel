# Semana 10 — Painel da turma

As 12 lacunas do projeto da aula foram concluídas. Inclui também nova tentativa e decremento de entregas.

## Executar

Use Node 22.12+ ou 24.

```
npm ci
# Windows PowerShell:
Copy-Item .env.example .env
npm run dev
```

Antes de iniciar, copie .env.example para .env. A configuração usa VITE_API_URL=/api/alunos. O .env não é rastreado no Git.

## Conferir

```
npx tsc -b
npm run lint
npm run build
```

Busca por LACUNA em src: 0 resultados. O mini-servidor funciona somente em npm run dev; os dados ficam em memória e reiniciam com o Vite.
